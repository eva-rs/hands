# Changelog

Заметные изменения рук, свежее сверху. Формат: дата — список; ломающие
изменения протокола/конфига помечаются **(ломающее)**.

## 2026-07-29

- Первая версия. Протокол 1: кадр из двух длин, JSON-шапки и сырого тела;
  операции `ping`, `stat`, `list`, `read`, `write`, `write_at`, `find`,
  `mkdir`, `remove`, `rename`, `exec`; рукопожатие с версией и потолками
  машины; коды отказов вместо угадывания по тексту.
- Транспорт — собственный порт демона: он сам аутентифицирует по
  ssh-ключам (`authorized_keys`), внутри канала идут наши кадры. Ssh-демон
  на машине не нужен, ssh-бинарь у клиента — тоже. Криптография не своя:
  рукопожатие, шифр и проверка подписи — реализация протокола SSH
  (`russh`). Ключ машины заводится сам при первом запуске; клиент может
  его запинать и тогда не примет чужого на том же адресе.
- Клиентская библиотека: одно долгое соединение, операции идут по нему
  вперемешку, разрыв переживается переподключением. Своя машина
  обслуживается теми же операциями прямо в процессе, без сети.
- Флейк с пакетом, dev-оболочкой и NixOS-модулем `services.eva-hands`:
  юнит, ключи, порт и потолки.
