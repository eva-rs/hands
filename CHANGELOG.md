# Changelog

## Не выпущено

- Протокол 3: ответ `exec` и клиентский `Output` отдельно передают
  код выхода, сигнал и фактический таймаут. При таймауте сохраняется уже
  полученный stdout/stderr; процессная группа сначала получает SIGTERM, затем
  SIGKILL после короткого ожидания. `Output::ok()` учитывает таймаут и сигнал.

- Операция `fetch`: скачивание URL прямо на машину, потоком в temp-сосед и `rename` —
  байты не едут через провод, потолок размера задан `max_bytes`/`max_write`, а не кадром.
  `path` с завершающим `/` — каталог: имя листа берётся из `Content-Disposition`, иначе из
  хвоста URL, и приезжает обратно в ответе вместе с `media_type` и `final_url`. Прокси
  задаёт вызывающий — своей сетевой политики у рук нет. Новый лимит `fetch` (по умолчанию
  включён). Версия протокола не менялась: старый демон ответит на неё `Invalid`.
- **(ломающее)** Протокол 2: добавлены фоновые exec-сессии — `ExecStart`/`ExecPoll`
  (long-poll)/`ExecInput`/`ExecKill` с реестром сессий в `Ops` (общий для local и remote).
  Клиент: `exec_start`/`exec_poll`/`exec_input`/`exec_kill`. `Psk` получил `PartialEq`/`Eq`.

## Ранее в этой ветке

- Руки переписаны с нуля. Транспорт — Noise `NNpsk0` (`snow`) с симметричным
  pre-shared ключом (`SecretString`, 32 байта через HKDF-SHA256): без ключа handshake
  не проходит. Бутстрап демона — на фреймворке eva (`App` + `Supervisor`). Единый API
  `Hands` для локального и удалённого режима; операции shell/файлы/поиск и потоковый
  перенос файлов (`copy`). Протокол версии 1.
